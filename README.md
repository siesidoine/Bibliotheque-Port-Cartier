# Bibliothèque municipale de Port-Cartier

## Description

Application Web développée dans le cadre de l'AEC en Programmation et analyse. Ce projet permet de gérer les activités d'une bibliothèque municipale, notamment les membres, les employés, les documents, les prêts, les réservations et les frais, à travers une interface Web moderne et une base de données relationnelle.

## Fonctionnalités

- Authentification des utilisateurs
- Tableau de bord
- Gestion des membres
- Gestion des employés
- Gestion des documents (livres, films, CD, jeux, consoles)
- Gestion des prêts
- Gestion des réservations
- Gestion des frais
- Opérations CRUD (Créer, Lire, Modifier, Supprimer)

## Architecture

Le projet suit une architecture **MVC (Model-View-Controller)** afin d'assurer une bonne séparation entre les données, la logique métier et l'interface utilisateur.

## Installation

### 1. Cloner le dépôt

```bash
git clone https://github.com/siesidoine/Bibliotheque-Port-Cartier.git
```

### 2. Accéder au projet

```bash
cd Bibliotheque-Port-Cartier
```

### 3. Installer les dépendances

```bash
pip install -r requirements.txt
```

### 4. Lancer l'application

```bash
python app.py
```

### 5. Ouvrir l'application

Accéder à l'application depuis votre navigateur à l'adresse :

```
http://127.0.0.1:5000
```
